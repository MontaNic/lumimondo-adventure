# Lumimondo Adventure

Piccolo RPG educativo in italiano per bambini di 6-8 anni, scritto su misura per un
bambino di nome Pietro. Si esplora un mondo di creature luminose (i **Lumini**), si
imparano numeri e parole, si fanno gare e coccole. Zero violenza, zero punizioni:
perdere una sfida non toglie mai niente, si riprova e basta.

Questo repository contiene **il gioco già pronto da servire**: HTML, CSS e JavaScript
vanilla, nessun framework, nessun passaggio di build. Si apre servendo questa cartella
con un qualsiasi server statico.

- **Grafica e personaggi**: originali, creati per questo progetto.
- **Voci**: generate e incluse come MP3 — il gioco parla, non serve la sintesi vocale.
- **Salvataggi**: restano nel browser di chi gioca. Dal menu si può scaricare un file
  di backup e ripristinarlo altrove.
- **Funziona offline**: è una PWA, si può aggiungere alla schermata Home del tablet.
- **Leggero**: al primo avvio scarica meno di 3 MB.

Progetto personale, senza fini commerciali.
